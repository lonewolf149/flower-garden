# A Garden of Flowers 🌷

A romantic, responsive flower-garden website made with vanilla HTML, CSS, and JavaScript.

## Features
- Animated typewriter introduction
- Night-sky gradient, twinkling stars, moon glow, and drifting fireflies
- 20 glowing flowers with nine color palettes
- Click flowers to change their colors and create sparkles
- Plant additional roses (up to 32 flowers total)
- Optional synthesized chime sounds using the Web Audio API
- Romantic message dialog
- Responsive layout for phones and desktop
- No build tools, package manager, or external JavaScript dependencies

## Run it
1. Extract `romantic_garden.zip`.
2. Open `index.html` in a modern browser.

For a local server (optional), open a terminal in the project folder and run:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

Google Fonts are loaded online; system serif fonts are used as fallbacks if you are offline.
